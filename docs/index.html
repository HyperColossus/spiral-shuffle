NEED TO KNOW

Questions from
the other side.

A few things to know before you begin your own journey through the shuffled Spiral.

Is this the official Wizard101 server?

No. Spiral Shuffle is an independent fan-made randomizer project and is not affiliated with, endorsed by or operated by KingsIsle Entertainment.

Do I use my official Wizard101 login?

No. Spiral Shuffle uses its own accounts. When registration is available, make a separate username and password here; never reuse your official game credentials.

Can I play with friends in another house?

Yes, once the server's public game connection is enabled. Everyone needs a compatible client and their own account to connect.

Where can I get the game client?

You will need your own legally obtained, compatible installation. This website does not host or distribute copyrighted game client files or proprietary assets.

Why can't I sign up yet?

This website runs on GitHub Pages, which hosts static files only. Account registration will become available when a secure registration API is connected to the live Imlight server.
